# 三端同步说明

本项目采用 **本地 ↔ 服务器 ↔ GitHub** 三端同步架构。

## 架构

```
本地电脑（C:\Users\潘梦展\Documents\finance-ai-git）
        │  git push / git pull（走 SSH，端口 22）
        ▼
服务器 /opt/finance-ai（同步中枢，同时也是运行环境）
        │  post-receive 钩子自动转发
        ▼
GitHub：github.com/zxcNB666PMZ/TB
```

## 为什么这样设计

- 本地访问 GitHub 的 HTTPS 被干扰（连接重置），SSH 也不稳定
- 服务器访问 GitHub 正常
- 所以让服务器当"中转站"：本地只需要连服务器

## 日常操作

### 本地改代码

```bash
cd C:\Users\潘梦展\Documents\finance-ai-git

# 1. 改文件
# 2. 看改了什么
git status
git diff

# 3. 提交
git add -A
git commit -m "说明改了什么"

# 4. 推送到服务器（同时自动同步到 GitHub）
git push origin main

# 5. 重启服务生效
ssh root@8.140.220.172 "systemctl restart finance-ai"
```

### 服务器上改代码

```bash
ssh root@8.140.220.172
cd /opt/finance-ai

# 1. 改文件（或用 VSCode Remote）
# 2. 提交并推送
git add -A
git commit -m "说明改了什么"
git push origin main          # 推到 GitHub

# 3. 本地拉取
git pull origin main
```

### 改坏了要回滚

```bash
# 丢弃所有未提交的修改
git checkout -- .

# 回到上一个提交
git reset --hard HEAD~1

# 看历史
git log --oneline -10
```

## 关键配置

| 配置 | 位置 | 说明 |
|---|---|---|
| 本地远程地址 | `ssh://root@8.140.220.172/opt/finance-ai` | 本地推送目标 |
| 服务器远程地址 | `git@github.com:zxcNB666PMZ/TB.git` | 使用 deploy key |
| 服务器接收策略 | `receive.denyCurrentBranch = updateInstead` | 推送后自动更新工作区文件 |
| 自动转发钩子 | `/opt/finance-ai/.git/hooks/post-receive` | 收到推送后自动推 GitHub |

## 不纳入版本管理的内容

| 文件/目录 | 原因 |
|---|---|
| `.env` | 含数据库密码、API 密钥 |
| `.venv/` | Python 虚拟环境，体积大 |
| `__pycache__/` | 编译缓存 |
| `*.bak` | 手动备份 |
| `.health_state.json` | 运行时状态 |

## 服务器目录中被排除的仓库内容

服务器通过 sparse-checkout 排除了 `docs/`、`frontend/`、`archive/`、`.devcontainer/`，
这些是文档和前端代码，不需要部署到服务器。
