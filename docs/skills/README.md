# 工程能力补齐 · Skill 集

> 针对「财务 AI 助手」项目当前的 5 个短板，每项一份可执行的操作手册。
> 路径约定：服务器代码在 `/opt/finance-ai`，本地仓库在 `D:\TB`（或任意 clone）。

## 清单与建议顺序

| # | Skill | 解决什么 | 耗时 | 难度 |
|---|---|---|---|---|
| 01 | [自动化测试](01-automated-testing.md) | 改代码不知道会不会崩 | 半天 | ⭐⭐ |
| 02 | [CI/CD](02-ci-cd.md) | 靠手动 scp 部署，易出错 | 半天 | ⭐⭐⭐ |
| 03 | [Docker 化](03-docker.md) | 换机器要重装一遍 | 一天 | ⭐⭐⭐ |
| 04 | [监控告警](04-monitoring.md) | 服务挂了没人知道 | 2 小时 | ⭐ |
| 05 | [数据库迁移 Alembic](05-alembic.md) | 改表靠手写 SQL，易漏 | 半天 | ⭐⭐ |

**建议顺序：01 → 04 → 03 → 02 → 05**

理由：
1. 先有测试，后面任何改动才有安全网
2. 监控最简单、收益最直接，先拿到"服务挂了立刻知道"的能力
3. Docker 解决环境一致性，是 CI 部署的前提
4. CI 建立在测试和 Docker 之上
5. Alembic 是数据库演进工具，最后补

## 每份文档的结构

- **目标** — 做完能达成什么
